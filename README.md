# 베리숲 점검 에이전트

베리숲 모험학교의 오류와 발전 방향을 점검하는 Codex용 프롬프트형 에이전트입니다.

## 사용 방법

1. 이 저장소를 Codex 프로젝트로 열거나, `AGENTS.md`를 베리숲 작업 폴더에 둡니다.
2. 프로젝트 대화에서 **“점검해줘”**라고 말합니다.
3. 에이전트가 [게임 소스](https://github.com/yangyeontae-blip/math)와 [공개 게임](https://yangyeontae-blip.github.io/math/)을 확인하고, 접근 가능한 로컬 사본도 살핀 뒤 근거가 있는 오류와 개선안을 보고합니다.

점검만 요청하면 파일을 수정하거나 배포하지 않습니다. 원하는 개선안의 번호를 선택해 별도로 수정을 요청할 수 있습니다. 게임 저장소 자체에도 같은 호출 방식의 `AGENTS.md`가 있습니다.
